# ![](https://me.lukas-bownik.net/img/logos/pikacloud_note.svg)
使用 Vue.js 和 Fetch API 编写的 Pika Note SPA 应用程序。

## 主要用途

PikaNote 的主要目的是作为 PikaCloud 的笔记应用程序。我自己用它来记录笔记或一些下载链接，但在未来的功能中，在 PikaCore 中生成永久下载链接也将会在 PikaNote 中创建一条包含链接信息和资源名称的笔记。

## 功能列表

PikaNote 目前具有以下功能：
- [x] 能够创建笔记并编辑现有笔记，
- [x] 笔记可从 MD 动态格式化为可视化形式，
- [x] 在查看保存的笔记时允许点击链接。
